### Backend

1. **기념일 기반 푸시알림 구현 질문**

- 현재 저희 요구사항중에 커플들이 설정해놓은 기념일 당일이 되면 그 날 0시에 해당 내용을 푸시알림으로 전송하는 기능이 있습니다.
- 그러면 spring에서 제공하는 스케줄러를 사용해서 0시마다 기념을 내용을 담고 있는 Anniversary테이블의 날짜 필드를 모두 검색해서
  오늘 날짜와 Anniversary테이블의 날짜 필드가 같은 경우 해당 기념일을 추가한 커플들에게 푸시알림을 전송하는 알고리즘으로 구현해야할 것 같은데
  이렇게 하면 당장 밋업때까지는 사용하는 유저가 적으니 푸시알림이 금방 전송되겠지만 저희가 실제로 배포해서 사용자가 늘어날때 푸시알림이 제때(0시에) 전송되지 않을 수도 있고, 서버에 부하가 발생하는 등의 리스크가 발생할 것으로 보입니다.
- 이렇게 대규모의 데이터를 처리하는 데에는 어떤 방법이 적절한지, 유저가 많이 짐에도 불구하고 푸시알림이 해당 유저로부터 딜레이 되지 않고 전송될 수 있도록 하는 방법은 무엇인지 전문가분들의 조언을 구해보고 싶습니다.

2. **부하테스트 질문**

- 저희가 이번 밋업때에는 단순 기능 구현으로 끝나는 것이 아닌 부하테스트를 통해서 성능향상에도 기여하고 싶다는 마음이 큽니다.
- 현업에서 자주 사용하시는 부하 테스트 기법들이 있는지 또 그 방법은 무엇인지 조언해주시면 감사하겠습니다!
